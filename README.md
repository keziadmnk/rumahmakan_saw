# Sistem Pendukung Keputusan untuk Pemilihan Rumah Makan Mahasiswa Universitas Andalas

Aplikasi web ini dirancang untuk membantu mahasiswa Universitas Andalas dalam memilih rumah makan terbaik dengan menggunakan metode *Simple Additive Weighting* (SAW).

## Kebutuhan Sistem

- Web browser
- phpMyAdmin
- VSCode atau editor teks lainnya
- XAMPP

## Panduan Menjalankan Aplikasi

### Melalui XAMPP

1. Clone atau unduh repositori ini.
2. Import database bernama `rumahmakan_saw` ke dalam phpMyAdmin.
3. Pindahkan folder repositori yang telah diunduh ke direktori `htdocs` milik XAMPP.
4. Pastikan XAMPP sedang aktif dan berjalan.
5. Akses aplikasi melalui browser di alamat `localhost/rumahmakan_saw` (atau sesuaikan dengan nama folder repositori yang digunakan).

### Melalui VSCode Langsung

1. Clone atau unduh repositori ini.
2. Import database `rumahmakan_saw` ke phpMyAdmin.
3. Buka folder repositori menggunakan VSCode atau editor lainnya.
4. Jalankan terminal di dalam VSCode dan ketik perintah `php -S localhost:3000`.
5. Buka browser dan akses `localhost:3000` untuk menjalankan aplikasi.
